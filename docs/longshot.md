# Longshot architecture review

Reviewed November 22, 2026. Both the Forgejo branch endpoint and Git's advertised HEAD returned `main` at `a2dc5385901812d183c4b7f0f9d48b295f17a510`. Longshot continues Hookshot and incorporates work from mkw-recomp and a64-kit. The user-facing launcher is a separate product that obtains the Longshot builder. [Pinned tree](https://git.magicbean.dev/MagicBeanDev/Longshot/src/commit/a2dc5385901812d183c4b7f0f9d48b295f17a510) · [Official site](https://longshot.magicbean.dev/)

Longshot's game selector names *The Legend of Zelda: Ocarina of Time* for Nintendo Switch 2, version 131072 and build prefix `e0f3ccfa`. Its build driver checks the executable build before lifting. Its title table maps the Zelda program, and its host includes title-specific hooks and substitutions for damaged files. Copying its layout or hooks into Fortune's Weave would require independent evidence for each hook and for every ABI binding. [Game contract](https://git.magicbean.dev/MagicBeanDev/Longshot/src/commit/a2dc5385901812d183c4b7f0f9d48b295f17a510/recomplauncher.json) · [Builder](https://git.magicbean.dev/MagicBeanDev/Longshot/src/commit/a2dc5385901812d183c4b7f0f9d48b295f17a510/nx2/make_game.py)

The `nx2` pipeline lays out the NSO image, resolves imports, lifts AArch64 instructions to C and compiles the generated chunks with Clang. The host implements Horizon interfaces. A separate Vulkan renderer replays NVN2 commands and translates shaders with Eden-derived code. The loader in `host/rx_backend.c` expects the Longshot renderer ABI. Its native test suite includes submitted shader fixtures with output checks, and a CI job selects the llvmpipe device under Linux. Results from that project do not establish Fortune's Weave rendering on this host. Its README applies GPL-3.0-or-later to Longshot and links the included GNU GPL v3 text. Renderer provenance records additional file-specific licenses for incorporated code. Setup can clone a separate tooling repository. FagriShot uses Longshot as an architectural reference only. No Longshot sources, launcher binaries, artwork, addresses, saves or updater were incorporated.
